ローラー練習2026.11.18

AIに練習が緩いと文句を言った翌日、35分で練習を投げ出した私

昨日の自分はどこへ行ったのか

昨日、AIから今日のメニューとして提案されたのは、220Wで60分のベース走だった。最近は70分でも走れているし、休養日を設けていない割には疲労も感じていなかった。それなら70分で良くない？　なんなら80分でもいいんじゃない？　そう言って、自分から練習時間を延ばした。

そして今日。35分で投げ出した。AIに練習が緩いと散々言っておいて、これである。

SSTよりも苦手なベース走

今日は少し身体が重かった。ただ、まったく踏めないというわけではない。メインの約35分間も平均216Wを維持できていた。どうにも苦手なのが、この何とも言えない中途半端な強度だ。楽なわけではないが、SSTのように明確にきついわけでもない。それが延々と続く。

一昨日はSST20分×3本を267W、270W、278Wでこなしているのに、今日は216Wで約35分。もちろん、その日の疲労状態も違うので単純には比較できないが、一定の出力で長時間走り続けることは、どうも精神的に苦手らしい。35分ほど経ったところで、もういいやと思ってしまった。そこからは強度を落とし、全体で1時間ほど走って終了した。

約26km・NP198W・TSS47

  • 全体25.71km / 1時間00分07秒
  • 負荷平均191W / NP198W / IF0.685 / TSS46.5 / FTP設定289W
  • 心拍・回転平均111bpm / 最大125bpm / 平均82rpm
  • メイン約35分 / 216W / 心拍平均117bpm / 81rpm

グラフを見ても、メインの約35分は出力がそれほど崩れていない。

さすがに疲れが出てきたのか？

11月10日から今日までの9日間で、計測できているTSSの合計は810.5。これにはマウンテンバイクでのお出かけは含まれていない。この間、完全休養日はなかった。

今日のAI相談

自分で練習時間を延ばしたのに、35分で投げ出しました。今日は少し身体が重くて、一定の強度が延々と続くのがどうも苦手で。

練習の単調さだけでなく、蓄積した疲労も影響していた可能性があります。11月10日から9日間で計測できたTSSだけで810.5、完全休養日はありません。

昨日までは本当に疲れを感じていなかったんですけど。

感じていないことと、疲労がないことは別です。単調さが苦手なら、一定の220Wにこだわらず、210Wと230Wを10分ずつ交互に繰り返す方法もあります。

疲労がないと思っていたのは、自分だけだったのかもしれない。今日の身体の重さを考えると、そう言われても反論しにくい。210Wと230Wの交互案は、平均出力は同じでも、区切りがあるだけで気分は変わりそうだ。

ペダリングの感覚は悪くなかった

メニューは完遂できなかったが、一昨日見つけたペダリングの感覚は今回も再現できたと思う。

  • 尾てい骨から回す感覚
  • 後輪を回すイメージ
  • ペダルを大きく回す意識

相変わらずうまく言語化できないが、一度きりの感覚ではなさそうだ。今日の数少ない収穫である。

うまくいかない日もある

富士ヒルゴールドを目指している以上、練習の負荷はしっかりかけたい。とはいえ、負荷を増やせば毎回うまくいくというわけでもない。AIにもっときつい練習を提案してくれと言っておきながら、今日は自分で延ばしたベース走を途中で投げ出した。我ながら面倒な人間である。

こういう日も含めて、富士ヒルゴールドへの挑戦の記録として残しておこうと思う。
