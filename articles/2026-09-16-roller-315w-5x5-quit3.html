ローラー練習2026.09.16

315W×5分×5本、3本でやめた。脚ではなく気持ちが先に切れた

今日はローラーで5分走。目標は前回の4本から1本増やして、315W×5分×5本、レスト5分である。

前回は315W前後で4本を完遂できていて、4本目の最後はまだ余力があった。なので今回は、出力を上げるのではなく「同じ315Wで5本揃える」がテーマ。

44分36秒・NP252W・TSS61.9

  • 全体22.83km / 44分36秒 / 平均216W / NP252W / IF0.917 / TSS61.9
  • 心拍・回転平均128bpm / 最大160bpm / 平均82rpm
  • 効果有酸素TE3.3（ハード）/ 無酸素TE0.0 / 運動負荷114

短時間だが、5分走を3本やったので、それなりに負荷は入っている。パワーはゾーン5以上に14分42秒。3本×5分がほぼそのまま高強度側に乗っている。一方で心拍ゾーン5はゼロだった。

316W → 315W → 317W。ここまでは綺麗に揃った

  • 1本目316W / 心拍平均143bpm
  • 2本目315W / 心拍平均149bpm
  • 3本目317W / 心拍平均151bpm

3本とも315W±2Wに収まっている。心拍は普通に上がってはいるものの、完全に限界という感じではなかった。

前回までと3本目を並べると、こうなる。

  • 9月8日313W → 315W → 309W → 302W（3分で終了）/ 最大心拍163bpm
  • 9月12日316W → 318W → 317W → 322W（4本完遂）/ 最大心拍170bpm
  • 今日316W → 315W → 317W → 4本目に入らず / 最大心拍160bpm

3本目の時点では9月12日とほぼ同じで、9月8日より8W高い。ここまでの内容で見れば、崩れる兆候は出ていなかった。

でも、4本目に入らなかった

問題はここ。脚が終わったわけではない。呼吸が限界だったわけでもない。単純に「今日はもういいかな」となってしまった。つまり、身体ではなく気持ちが先に切れた。

前回の5分走では4本やれているので、今日の3本で能力的に限界だったとは思っていない。最大心拍も160bpmで、4本完遂した9月12日の170bpmまでは上がっていない。だから今日は「315W×5分×5本に失敗した」というより、「3本終わったところで、自分からやめた」という方が正確である。

こういう失敗もある

高強度の練習は、脚や心肺だけではなく、気持ちも使う。5分という時間も地味に長い。1本終わって5分休んで、また5分。それを何本も繰り返す。今日は身体が拒否したというより、「また5分やるのか……」という気持ちの方が勝ってしまった。

こういう日もある。ただ、ここで変に「自分は315Wを5本できない」と判断するのは違うと思っている。今日のデータを見る限り、そこまでは追い込めていない。

今日のAI相談

316、315、317W。3本でやめました。脚でも呼吸でもなく、気持ちが切れただけです。

数字もそう言っています。3本目が一番高くて、最大心拍は160bpm。身体の限界ではありません。

ですよね。じゃあ実質5本クリアみたいなものですね。

記録は3本です。次回、1〜4本目は途中でやめるかを考えないでください。

次回も315W×5本

なので次回もメニューは変更しない。315W×5分×5本、レスト5分。320Wに上げるのはまだ先で、まず315Wで5本揃える。

次回は1〜4本目までは余計な判断をしない。「キツいからやめる」ではなく、本当に身体が無理なのかを見る。そして5本目まで入れたら、最後に余力があれば少し上げる。それで十分である。

今日やってみて思ったこと

最近は調子の良い日が続いていた。太平山では6分45秒・340W。登りそのものは普通に苦しかったが、それ以外の区間は呼吸に余裕があり、ペダリングの感覚もかなり良かった。その翌日はアクティブレスト。流れとしては悪くないと思っていた。

でも今日は、身体より先に気持ちが切れた。トレーニングは毎回データ通りにはいかない。脚が動く日もあれば、気持ちが乗らない日もある。今日は後者だった。

ただ、315Wを3本揃えた事実は残る。次回は5本。また同じところからやる。

  • 4本目以降の心拍今日は3本目で151bpm。4本目・5本目でどこまで上がるか
